# 📋 Gerenciador de Tarefas

Aplicação web de lista de tarefas feita com **HTML, CSS e JavaScript puro** (sem bibliotecas).

## Funcionalidades
- Adicionar, editar, concluir e remover tarefas
- Três níveis de prioridade com cores diferentes
- Filtros: todas, pendentes e concluídas
- Contador de tarefas pendentes
- Os dados ficam salvos no navegador (`localStorage`)

## O que pratiquei neste projeto
- Manipulação do DOM e eventos
- Arrays, objetos e funções (`find`, `filter`, `forEach`)
- Armazenamento local com JSON
- Layout responsivo com Flexbox
- Cuidado com segurança: uso de `textContent` em vez de `innerHTML` para dados digitados

## Como usar
Abra o arquivo `index.html` no navegador ou acesse a versão online (GitHub Pages):
`https://sanderemanuelsc-stack.github.io/gerenciador-de-tarefas/`
